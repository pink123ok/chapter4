# Chapter 4 — Personalized Route Recommendation Based on Dual-Dimensional Historical Profiles

> **硕士学位论文第四章实验代码**｜基于双维历史行为画像与条件 Logit / Path-Size Logit 的多需求路径推荐  
> **说明依据**：《第四章说明文档》（整理日期：2026-10-31）。本文介绍文档已记录的实验流程与结果，具体运行以仓库实际脚本和本地真实数据为准。

## 1. 项目简介

本项目面向**未知起终点（OD）的个性化路线推荐**，以 2024 年 12 月曼谷出租车轨迹及固定有向路网为实验基础。研究流程为：

1. 严格按时间隔离校准、训练、验证和最后三天的测试数据，避免未来路线信息进入推荐过程。
2. 利用第三章 **UDPPM++ 双维软聚类**，从出发前已完成的历史行程中形成车辆关联的 **8 维经济／舒适历史行为画像**。
3. 针对最后三天的未知 OD，在固定曼谷有向 GraphML 路网上生成自然候选路线，计算静态道路属性及 Path Size。
4. 在历史条件候选集合上拟合 **MNL / PSL / UDPPM 增强条件选择模型**，冻结参数后对未知 OD 的自然候选评分和排序。
5. 面向**经济优先、舒适优先、均衡**三种需求，输出 Top-3 推荐，并从目标权衡、多样性、画像敏感性和历史选择解释能力等角度评价。

**研究边界：**“历史行为画像”由车辆 ID 关联的历史轨迹得到，不能直接等同于司机或乘客的稳定主观偏好；经济性与舒适性评分是基于道路结构的**代理指标**，并非实测出行成本或乘坐舒适度。

| 模型 | 描述 |
|---|---|

| `UDPPM_Econ_PSL_L2` | PSL + 经济历史画像与道路属性交互 |

### 模块五：三需求连续评分与 Top-3 推荐（正式 v4）

- **需求场景**：经济优先、舒适优先、均衡。
- **目标代理**：经济性依据同一 OD 下的路线长度代理；舒适性根据转弯密度、路段密度及道路等级结构等静态代理构成；均衡目标为经济／舒适代理各占 0.5。
- **综合评分设定**：`0.70 × 当前需求目标 + 0.30 × 冻结模型概率`。
- **Top-3 多样性重排设定**：`λ = 0.18`，最大重叠阈值 `0.80`。
- **主要输出**：`23_连续需求_全部候选三场景评分.csv.gz`、`24_连续需求_三场景 Top3 主方法.csv.gz`、`26_连续需求_逐 OD 逐场景逐方法指标.csv`、`28_目标冲突 OD_切换后实际改善统计.csv`、`31_连续需求_来源防泄漏与统计审计.json`。

上述权重和阈值属于**研究设定**，不是训练得到的最优参数；v4 设置经过查看测试 OD 后的探索性调整，不应称为全新独立测试集上的最优泛化结论。

### 模块六：独立复算、消融与反例审计

- 使用修复版统计脚本，避免早期道路重叠指标缺失值分母处理问题。

- **主要输出**：`03_冲突 OD_路线切换与道路属性变化_Bootstrap.csv`、`05_五方法_同 OD 配对检验及 Holm 校正.csv`、`08_强冲突 OD_高绕行与转弯反例审计.csv`、`09_论文核心结论指标表.csv`、`10_实验口径与方法局限.json`。

## 7. 主要实验结果（说明文档记录值）

### 7.1 未知 OD 候选覆盖

| 指标 | 结果 |
|---|---:|
| 最后三天测试 OD | 4,469 |
| 至少 1 条自然候选的 OD | 4,466（99.93%） |
| 至少 3 条自然候选的 OD | 4,192 |
| 自然候选路径总数 | 37,383 |
| 平均每个测试 OD 的候选数 | 约 8.365 |

### 7.2 需求切换与道路属性权衡

在 **1,224 条强目标冲突 OD** 中，经济优先切换为舒适优先时，有 **894 条** OD 的首选路线发生变化（**73.04%**）。舒适优先相对经济优先，平均表现为：

| 指标变化 | 结果 |
|---|---:|
| 路线长度 | +4.437675 km |
| 绕行比 | +0.371362 |
| 每公里转弯密度 | −0.210854 |
| 每公里路段密度 | −2.381294 |
| 快速路占比 | +0.137079 |
| 舒适代理得分 | +0.214457 |
| 经济代理得分 | −0.548184 |

这些变化表示**道路结构代理之间的权衡**，不是实测主观舒适度提升。尤其要注意：每公里转弯密度下降**不等于全程总转弯数下降**；文档的全程估算转弯数差值对应舒适路线平均反而多约 0.448 次。

### 7.3 历史选择模型：8 维画像的概率解释增量（实验 68）

比较同一个冻结 UDPPM 模型在真实历史画像与训练期群体参考画像输入下的条件负对数似然（NLL，越低越好）：

| 模型 | 真实画像 NLL | 参考画像 NLL | 改善量（参考 − 真实） |
|---|---:|---:|---:|
| 经济 UDPPM | 0.862389 | 0.876809 | +0.014421 |
| 舒适 UDPPM | 0.860036 | 0.877225 | +0.017189 |
| 双维 UDPPM | **0.857804** | 0.877209 | **+0.019405** |
| 基础长度加权 PSL（无画像） | 0.875964 | — | — |

- 双维真实画像模型：**MRR = 0.823742，Hit@1 = 70.22%**，属于**历史条件候选集合**评价。
- 双维画像相对相同模型的参考画像，NLL 相对下降 **2.21%**；与基础 PSL 的 NLL 相比相对下降 **2.07%**。
- 以 **1,951 辆验证车辆**进行车辆聚类 Bootstrap，双维参考−真实 NLL 改善为 **0.019405**，95% CI 为 **[0.014824, 0.024239]**，Holm 校正后 `p ≈ 0.003`。
- 真实画像改善了 **57.58%** 验证 OD 的 NLL，但也有 **42.42%** 的验证 OD 变差。Hit@1 提升约 **0.42 个百分点**，车辆级检验 `p ≈ 0.056`，**不应宣称 Hit@1 显著提高**。
- 有效验证 OD 为 **4,755**，其中 **3,854 条（81.05%）** 的历史条件候选需要补入实际选择路线，因此此处的 Hit@1 **不能解释为最后三天未知 OD 的真实路线命中率**。

### 7.4 Top-3 对照与画像输入敏感性（实验 66／67）

- **实验 66**：完整 Top-3 的 **4,192** 条 OD 中，不同冻结模型的 Top-3 集合相同率依次为：经济 **95.78%**、舒适 **93.85%**、均衡 **92.63%**。
- **实验 67**：固定模型仅替换画像输入后，全部 OD 的 Top1 变化率为经济 **2.91%**、舒适 **3.58%**、均衡 **4.14%**；Top-3 集合变化率为 **4.10% / 5.51% / 6.61%**。
- 实验 67 中，重建概率最大绝对误差约 `5 × 10^-11`，与模块五的 **13,398 个 OD-需求场景** Top-3 排序全部匹配。

综上，历史画像在**条件概率解释**上具有可检验的小幅增量，但多数未知 OD 的 Top-3 候选集合不变；不能据此声称未知 OD 的真实路线命中率或主观舒适度有显著提升。

## 9. 已知限制

1. **代码与数据依赖**：上游大规模轨迹、OSM GraphML、历史条件候选等必须由真实数据准备流程得到；说明文档没有提供一键下载数据或完整环境锁定文件。
2. **历史画像的解释范围**：车辆关联历史不等同于驾驶员／乘客主观稳定偏好，冷启动情况下画像增量可能不成立。
3. **候选真值补入**：仅在历史条件选择训练／验证中允许；末三天自然候选中不得使用真实行驶路线。
4. **模型增量的适用范围**：实验 68 证明的是历史条件选择概率解释增量，不是独立未知 OD 导航准确率提升。
5. **需求与舒适代理**：没有真实乘客需求标签；舒适评价是道路结构代理，不代表实测舒适度。70%+30% 权重也不是训练获得的全局最优权重。
6. **上海与曼谷数据区别**：第二章在上海 OSM 上的 BERT／知识图谱语义融合结果，尚不能直接认定为已进入本章曼谷条件选择模型；如果论文声称已直接融合，须用真实数据流和特征列提供证据。
